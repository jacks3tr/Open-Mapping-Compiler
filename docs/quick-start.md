# Quick start

Open Mapping Compiler's normal workflow is offline and deterministic. Start with the [baseline mapping guide](../USAGE.md) to inspect schemas, create suggestions, review a mapping, verify it against samples, and run or compile the result.

Model assistance is optional. It produces reviewable draft suggestions and does not change the baseline workflow. See [model-assisted mapping](model-assisted-mapping.md) when you want to configure a provider.
